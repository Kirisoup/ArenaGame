# Arena Game
This is a dead simple 2D arena game with waves of two different kinds of enemies, gradually increasing in difficulty.

More than anything else, this is an experiment in building a game as simply as possible without overthinking its
implementation, in order to actually get a project finished and out there for once.

Game can be downloaded and played at https://jonkadelic.itch.io/arena-game.

Uses C# + Raylib.

## Retrospective
It feels very strange to have actually "finished" a project for once. This game contains everything it fundamentally
needs to, and nothing more. The code isn't great - the whole implementation is in one `Game` class and everything
touches everything else - but crucially, it *works*. I think the most important take-away is that you can save
perfectionism for later, because that's what tends to get in the way of actually making things. For now, everything in
here is "good enough", and to be honest, I'm pretty happy letting it stay that way. I'm never going to re-use anything
from this project other than the lessons I've learned from it.
